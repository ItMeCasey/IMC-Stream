HOME

Your screen: small parts you pick. Full pages are in the menu on the left.

MODULES

Everything in the app is a module. Hide pages you don't use, add links to your own pages, or install a module someone made (a .zip). A module can add a page, small Home widgets, or both.

ALL MODULES

ADD A LINK

Some websites refuse to be shown inside the app: those open in your browser instead.

INSTALL A MODULE (.zip)

A module is a folder with a module.json and your own web page. Zip it and install it here. Installed modules live in your data folder and are included in backups.

module.json
{ "name": "My Module", "icon": "★", "description": "What it does",
  "entry": "index.html",     // optional full page (a menu item); false = widgets only
  "widgets": [ { "name": "My Widget", "entry": "widget.html", "size": "s" } ]   // optional small Home parts (s, m, l, xl)
}

index.html   (any HTML/JS/CSS you like; it runs at /modules/<id>/)
