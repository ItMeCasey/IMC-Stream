WHAT THE BOT DOES

It runs inside this app (so it works while the app is running). It sets up your server (roles and channels in your style, with a welcome and a rules message, only adding what is missing), posts when you go live, and answers slash commands: /commands /games /tts /top /live /website.

1. MAKE THE BOT (ONE TIME, ON DISCORD'S SITE)

  1. Go to discord.com/developers/applications, log in and press New Application. Give it a name (that is the bot's name).
  2. Open the Bot tab. Press Reset Token, then Copy. You do not need to turn on any of the "intents".
  3. Paste the token here and press Save and check. The token stays on this PC and is never shown again.

2. ADD THE BOT TO YOUR SERVER

Save the token first.

Discord asks which server (you must be able to manage it) and shows the permissions the bot needs: manage roles and channels, post messages, and the permissions it hands to the Mods role. Press Authorize.

3. SET UP THE SERVER

It only ever adds what is missing. Nothing that is already there is changed, moved or deleted, so it is safe to run on a server you already use. The new channels get a welcome message, the rules and a how-to-use message; read-only channels (welcome, rules, announcements, go-live) only let the bot and the Mods post; the MODS category is private to the Mods role.
