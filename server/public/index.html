ALERTS

How alerts work

Press Test on any alert to see and hear it in the preview (and in OBS). Alerts use the best matching enabled rule: a higher minimum wins, so "Bits ≥ 1000" can override plain "Bits".

While paused, new alerts wait in line and play when you resume. Mute silences alert sounds and voices but still shows the banner. Mods can use !alerts pause|resume|skip|clear|mute|unmute.
