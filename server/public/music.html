ON STREAM & IN CHAT

Overlay: add a Browser source http://localhost:8420/overlays/nowplaying.html (700 × 220). It slides in while music plays and shows the art, title, artist, album and a live progress bar. Add ?mode=always to keep it up when paused, or ?mode=change&hold=12 to pop up for 12 seconds at the start of each song.
Chat: !song (everyone), mods: !skip !previous !pause !play !volume 50. Text sources can read now_playing.txt, now_playing_title.txt, now_playing_artist.txt from data/labels, and commands can use {now_playing}.
