TEXT-TO-SPEECH REWARD (CHANNEL POINTS)

A reward with a box for the message: when a viewer redeems it, their message is read out loud with the voice above (blocked words are never read) and the redemption is fulfilled. If the message cannot be read, the viewer is told why and the points are refunded. Needs Affiliate or Partner.

Other ways to use the voice: in Alerts, edit an alert and tick Read it aloud (e.g. bits and tips read the viewer's message). In Reward hooks, add a Speak aloud action so a channel point reward reads what the viewer typed. Mods can type !ttsskip to cut off the current speech.
