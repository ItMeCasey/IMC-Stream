WELCOME

Four quick steps and your alerts, chat bot and overlays are live. You can do this later from the Setup page.

1Connect Twitch

A browser page opens. Log in to Twitch if asked and press Authorize. The app only gets the permissions it needs for alerts, chat and your stream tools.

2Connect OBS

  1. In OBS open Tools, WebSocket Server Settings.
  2. Tick Enable WebSocket server (leave the port as it is). If you set a password, type it below.

3Install the scenes

Adds the ItMeCasey scene collection to OBS: Starting Soon, Gameplay, Just Chatting, Full Cam, Be Right Back and Ending, with all the overlays in place. It never touches your existing collections.

Then in OBS choose Scene Collection, ItMeCasey. Open the Webcam source and pick your camera, and set Game Capture to your game.

4Try it

Send a test follow alert. If you see it in OBS, everything works.
