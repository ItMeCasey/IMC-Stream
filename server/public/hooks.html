WHEN A CHANNEL POINT REWARD IS REDEEMED…

Each hook waits for a reward, then runs its actions in order: show an overlay alert, say something in chat, run a chat command, call a webhook, show a source or switch scene in OBS, give or take currency, change a counter, and mark the redemption done. Several hooks can match the same reward.
