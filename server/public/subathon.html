WHAT ADDS TIME

While the timer is running, these add time on their own (the overlay shows a "+10m" bump). Set an amount to 0 to turn one off. Leave the cap at 0 for no limit.

CHAT COMMANDS

!subathon   Subathon ready: 12:00:00
!subathon rules or !subrules  

Anyone can use those two. Mods can also type !subathon start 6h, +10, -5, pause, resume, reset, hide, show.
