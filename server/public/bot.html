YOUR VARIABLES & COUNTERS

Make your own pieces to reuse in any command, timer or event message. Text: {var.discord} always shows the same text. List: {var.mood} picks a random item each time. Counters ({counter.deaths+} adds one) are created the first time a command uses them. Mods can also type !setvar name text and !listadd name item in chat.

BUILT-IN COMMANDS

Mods can also manage commands from chat: !addcom name [-ul=moderator] [-cd=10] response, !editcom name new response, !delcom name. Other mod tools: !permit user (allow one link for 60s), !so channel, !game/!title (set), !addquote/!delquote, !counter name [+|-|set N|reset], !trivia, !raffle open|draw|close.

TIMERS

Repeating chat messages. A timer only fires if enough chat lines happened since its last post, so it won't talk to an empty room.

SPAM PROTECTION

The bot needs you logged in as the channel owner (or a mod). Exempt = that rank and above is ignored. Timeouts double for repeat offences within 10 minutes.
