HOW IT WORKS

The app keeps this stream's chat (without deleted messages, commands and bots) and asks Claude to summarise it, using the Claude Code program on this PC and your own Claude login, always with the cheapest model (haiku). You get an end-of-stream recap (what chat talked about, funny moments, unanswered questions, regulars) saved in Documents\ItMeCasey Stream\recaps, and a !recap command for mods that says in one line what chat has been talking about.

Privacy: the chat text is sent to Anthropic to be summarised. Turn off "send chatter names" to replace names with Viewer1, Viewer2...
